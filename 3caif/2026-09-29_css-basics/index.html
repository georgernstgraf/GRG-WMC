1 · Einstiegsfrage

Deine HTML-Seite ist fertig — aber sie sieht aus „wie ein Word-Dokument von 1998". Und dann hat deine Kollegin dieselbe Seite, will aber einen anderen Hintergrund.

  • Wie gibst du allen Absätzen eine Farbe — ohne jedes <p> anzufassen?
  • Warum ist die eine Box breiter als gedacht, obwohl width: 200px dasteht?
  • Und wie macht man eine Farbe durchsichtig?

Nach dieser UE formatierst du deine Seite mit CSS, kennst die drei Wege, Stile einzubinden, und verstehst das Box-Model.

2 · Ziel-Artefakt: das „Box-Model-Diagramm"

Jedes Element ist ein Kastl. Von innen nach außen:

┌─ margin ───────────────────────────────┐
│  ┌─ border ──────────────────────────┐ │
│  │  ┌─ padding ────────────────────┐ │ │
│  │  │        CONTENT (Text/Bild)   │ │ │
│  │  └──────────────────────────────┘ │ │
│  └───────────────────────────────────┘ │
└────────────────────────────────────────┘
   width/height = ???

Diese Frage — zählt width Padding und Border mit oder nicht? — ist der Klassiker. Die Antwort heißt box-sizing.

3 · Die drei Wege, CSS einzubinden

CSS kannst du auf drei Arten mit HTML verbinden. Alle drei sind erlaubt — sie haben aber unterschiedliche Rollen:

Weg 1 — Inline: das style-Attribut

Direkt am Element. Gut zum schnellen Ausprobieren, schlecht für eine ganze Seite.

<p style="color: #b3261e; font-weight: bold;">Achtung: rot und fett</p>

Weg 2 — Intern: ein <style>-Block im HTML

Mehrere Regeln auf einmal, aber nur für diese eine Datei.

<head>
    <style>
        p { color: #1c1c1e; }
        .wichtig { color: #b3261e; font-weight: bold; }
    </style>
</head>

Weg 3 — Extern: ein verlinktes Stylesheet (der Normalfall)

Eine eigene style.css, im head verlinkt. Ein Stylesheet für alle Seiten — das ist die saubere Trennung von Struktur und Darstellung.

<link rel="stylesheet" href="style.css">

/* style.css */
body { font-family: system-ui, sans-serif; background: #fafaf7; }
.wichtig { color: #b3261e; }
WegReichweiteWofür
style-Attributein Elementkurz testen, Sonderfall
<style>-Blockeine DateiDemo, kleine Einzelseite
<link>-Stylesheetbeliebig viele SeitenNormalfall — wiederverwendbar

Merksatz: Inline zum Probieren, verlinkt zum Arbeiten.

4 · Selektoren: wen trifft die Regel?

Für heute genügen drei Selektoren. (Vertiefung folgt in der nächsten UE.)

p { … }             /* Element: alle p auf der Seite */
.wichtig { … }      /* Klasse: alle mit class="wichtig" (wiederverwendbar) */
#start { … }        /* ID: genau ein Element (sparsam!) */
  • Klassen für Styling: <p class="wichtig">.
  • IDs für Anker und JavaScript — nicht fürs Styling.
  • Namen klein + Bindestrich: main-container, nicht MainContainer.

5 · Das Box-Model & box-sizing

Vier Flächen: content · padding · border · margin. Standardmäßig gilt content-box: width zählt nur den Inhalt — Padding und Border kommen obendrauf.

/* Standard: die Box wird breiter als 200px */
.karte {
    width: 200px;
    padding: 20px;
    border: 5px solid #6d28d9;
}   /* → tatsächliche Breite: 200 + 2·20 + 2·5 = 250px */

/* Rettung: border-box zählt Padding/Border in die Breite */
* { box-sizing: border-box; }
.karte { width: 200px; }   /* → bleibt 200px */

Merksatz: border-box an, Sorgen aus. Im Browser unter DevTools → Elements siehst du das Box-Model-Diagramm live.

6 · Farben & Deckkraft

Farben schreibt man hexadezimal oder als rgb/rgba. Das a in rgba() ist die Deckkraft (Alpha) von 0 (unsichtbar) bis 1 (deckend).

.titel { color: #6d28d9; }                  /* Hexadezimal */
.titel { color: rgb(109, 40, 217); }        /* Rot/Grün/Blau */
.schatten { background: rgba(109, 40, 217, 0.15); }  /* zart lila, durchsichtig */
  • color färbt die Schrift, background den Hintergrund.
  • rgba(…, 0.15) eignet sich für Overlays und dezente Flächen, ohne den Text darunter zu verlieren.

9 · Typische Fehler

  • Mehrere <link> zum selben Stylesheet oder CSS im body — genau einmal im head verlinken.
  • width „stimmt nicht": box-sizing: border-box fehlt.
  • Farbe wirkt nicht: Es gibt einen spezifischeren Selektor (ID schlägt Klasse schlägt Element) — DevTools zeigt, welche Regel gewinnt.
  • Box zu breit auf dem Handy: px statt rem/ % — oder Padding vergessen einzurechnen.
  • rgba(…, 15) statt 0.15: Alpha läuft von 0–1, nicht 0–100.
