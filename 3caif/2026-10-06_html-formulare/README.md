# HTML-Formulare (2026-10-06)

Lesson: 03_HTML-Formulare.pdf; Grundlage für das eigene Formular.


## Aufgabe

`index.html` „Formular" fertigstellen:  
- Texteingabe
- Radiobutton
- Checkbox
- Dropdown
- Mehrfachauswahl
- Mehrzeilige Textfelder
- Und ein weiteres Eingabefeld
- Beim Abschicken des Formulars soll der Mailclient aufgerufen werden und die eingegebenen Daten an „Ihre eMail-Adresse“ übermittelt werden. Die E-Mail soll vom Formular mit einem Betreff versehen werden. 

- Bonus: Pfichtfelder, pattern-matching

— Abgabe per Push bis 2026-10-13 00:00.
