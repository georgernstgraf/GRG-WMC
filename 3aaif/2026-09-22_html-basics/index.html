2 · Grundgerüst (Pflicht)

<!DOCTYPE html>
<html lang="de">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Über mich</title>
</head>
<body>
    <header>...</header>
    <main>...</main>
    <footer>...</footer>
</body>
</html>
  • <!DOCTYPE html> = HTML5, kurz und gut.
  • lang="de" hilft Screenreader + SEO.
  • charset + viewport sind Pflicht (Umlaute + Mobile).
  • Alles klein schreiben, alle Tags schließen.

3 · Semantik: die 7 Tags für heute

<header>  Kopf: Titel, Logo
<nav>     Navigation (nur wichtige Links)
<main>    Hauptinhalt (genau 1x pro Seite)
<article> eigenständiger Inhalt (Beitrag)
<section> thematische Gruppe
<aside>   Nebeninfo (Sidebar)
<footer>  Fuß: Autor, Copyright
Mein Blog

  • Über mich
