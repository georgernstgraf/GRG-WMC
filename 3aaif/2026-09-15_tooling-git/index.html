2 · Installieren (15 Min)

  1. Git: Windows winget install git.git · Mac brew install git. Test: git --version muss eine Version zeigen.
  2. VS Code: winget install vscode bzw. von code.visualstudio.com laden.
  3. Extensions: Live Server (Ritwick Dey) + W3C Web Validator. Danach VS Code neu laden.
  4. PowerShell-Skripte erlauben (Windows, einmalig): Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  5. Node LTS (Vorgriff Jahr 2, optional heute): winget install openjs.nodejs.lts

Aktualisieren danach mit winget upgrade --all bzw. brew upgrade.

3 · Git in 6 Befehlen

Git merkt sich jede Version deiner Dateien. GitHub ist die Ablage im Netz.

git config --global user.name "Dein Name"
git config --global user.email "deine@email.at"
git clone https://github.com/DEIN-USER/WMC.git
git status
git add .
git commit -m "Add index.html"
git push
  • status lügt nie — bei Unsicherheit zuerst aufrufen.
  • add . + commit -m "..." + push ist dein Dreiklang für jede HÜ.
  • Repo auf github.com mit Spengergassen-Mail anlegen, Name WMC, public, mit README.

4 · Live-Demo: erste Seite (20 Min)

  1. Ordner WMC in VS Code öffnen.
  2. Datei index.html anlegen, Grundgerüst per Emmet (! + Tab).
  3. Rechtsklick → Open with Live Server (Port 5500). Seite läuft lokal.
  4. DevTools öffnen (F12): Elements-Tab zeigt den DOM-Baum, Console zeigt Fehler.
  5. W3C Validator in VS Code laufen lassen — 0 Errors ist das Ziel.
  6. caniuse.com prüfen, z. B. ob CSS Nesting im Zielbrowser geht.
