2 · Einbinden (so, nicht anders)

<link rel="stylesheet" href="style.css">

In den head, genau einmal. Kein Style-Chaos im HTML — Ausnahme heute: gezielte Demos mit style-Attribut zum Vergleichen.

/* style.css */
body {
    font-family: system-ui, sans-serif;
    background: #fafaf7;
    color: #1c1c1e;
}
.main-title {
    color: rgba(109, 40, 217, 1);
}

rgba() = Rot/Grün/Blau + Alpha (Deckkraft 0–1). Beispiel: rgba(109, 40, 217, 0.15) für zarten Lila-Hintergrund.

3 · Box-Model: alles ist ein Kastl

Jedes Element = Content + Padding + Border + Margin (von innen nach außen). Der Klassiker-Fehler: width zählt per Default ohne Padding/Border.

* {
    box-sizing: border-box;
}
.card {
    width: 20rem;
    padding: 1rem;
    border: 2px solid #6d28d9;
    margin: 1rem 0;
}
content-box: wird breiter als 12rem
border-box: bleibt bei 12rem

Merksatz: border-box an, Sorgen aus. (DevTools → Elements → Box-Model-Diagramm ansehen!)

4 · Selektoren für heute (3 Stück genügen)

p { ... }            /* Element: alle Absätze */
.main-title { ... }  /* Klasse: wiederverwendbar */
#start { ... }       /* ID: genau einmal (sparsam!) */
  • Klassen für Styling (class="card"), IDs für Anker/JS — nicht für jedes Styling.
  • Klein + Bindestrich: main-container, nicht MainContainer.
