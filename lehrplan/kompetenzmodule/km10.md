## Lehrstoff (Wortlaut Anl. 1.10)

Komplexe verteilte Systeme, Multi-Tier-Systeme.

## Worum geht es?

Das Abschluss-Modul: alles Zusammenführen als **Multi-Tier-Gesamtsystem** —
React-PWA (Frontend) + konsumierte REST-API + Auth + Offline (→ Backend/POS) und
**strukturiertes Testen** als Qualitätspraxis (Vitest, React Testing Library mit
Rollen-/Query-Logik statt Implementierungsdetails, API-Mocks, Testpyramide
leichtgewichtig). „Aktuelle Technologien" = der Stack dieses Repos
(TS, React/Vite, PWA, Vitest).
