# 56KIF — WMC Jahr 2 (Kolleg)

Generischer Ordner für die Jahr-2-Blöcke des schulautonomen Fachs
**Webprogrammierung und Mobile Computing (WMC)** — **dieses Semester aktiv** (SJ 2026/27 WS).

| Feld | Wert |
|------|------|
| **Block** | Jahr 2 = Semester 5 (WS) + Semester 6 (SS) |
| **Semestrierung** | `5KIF` = WS · `6KIF` = SS |
| **Kohorten (Praxiscodes mit Zug-Präfix)** | `5AKIF` → `6AKIF` (Zug A, Kolleg) — weitere Züge (`56CIF` o. ä.) bei künftiger Besetzung anlegen |
| **Zeitmodell** | **3 h-Block/W** (Abendeinheit) → ~13 echte UE + 2 PLF pro Semester |
| **Einstieg** | mit Reifeprüfung, Berufsreifeprüfung oder Studienberechtigungsprüfung → Abschluss **Diplomprüfung** (Matura bereits vorhanden) |
| **Rechtsbasis** | BGBl. II Nr. 368/2022, Anlage 1.9 (6-sem Kolleg, Variante I.4); Referenz-Raster Anlage 1.10 (BGBl. II Nr. 262/2015 idF 383/2021), KM5–KM10 komprimiert |
| **Stack** | TypeScript · React + Vite (Node/npm) · Mini-Hono-Referenz (Deno) als Übungs-API · PWA · Vitest + RTL · **kein Backend-Stoff** (→ POS) |
