# 34AIF — WMC Jahr 1 (Aufbaulehrgang)

Generischer Ordner für die Jahr-1-Blöcke des schulautonomen Fachs
**Webprogrammierung und Mobile Computing (WMC)** in der Aufbaulehrgang-Form.

| Feld | Wert |
|------|------|
| **Block** | Jahr 1 = Semester 3 (WS) + Semester 4 (SS) |
| **Semestrierung** | `3AIF` = WS · `4AIF` = SS |
| **Kohorten (Praxiscodes mit Zug-Präfix)** | `3AAIF` → `4AAIF` (Zug A) · `3CAIF` → `4CAIF` (Zug C) |
| **Zeitmodell** | **faktisch 2 h/W** (schulautonome Verdichtung; lt. Stundentafel 1 h — Legitimation: Fußnote 1 Stundentafeln + § 3 VO) |
| **Einstieg** | ohne Reifeprüfung (Vorbereitungslehrgang/Fachschule/facheinschlägiger Lehrabschluss) → Abschluss **Reife- und Diplomprüfung** |
| **Rechtsbasis** | BGBl. II Nr. 368/2022, Anlage 1.9 (7-sem Aufbaulehrgang, Variante I.3); Referenz-Raster Anlage 1.10 (BGBl. II Nr. 262/2015 idF 383/2021) |
