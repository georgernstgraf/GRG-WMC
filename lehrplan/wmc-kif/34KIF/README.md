# 34KIF — WMC Jahr 1 (Kolleg)

Generischer Ordner für die Jahr-1-Blöcke des schulautonomen Fachs
**Webprogrammierung und Mobile Computing (WMC)** in der Kolleg-Form.

| Feld | Wert |
|------|------|
| **Block** | Jahr 1 = Semester 3 (WS) + Semester 4 (SS) |
| **Semestrierung** | `3AIF` = WS · `4AIF` = SS |
| **Kohorten (Praxiscodes mit Zug-Präfix)** | `3AKIF` → `4AKIF` (Zug A) · `3BKIF` → `4BKIF` (Zug B) |
| **Zeitmodell** | **faktisch 2 h/W** (schulautonome Verdichtung; lt. Stundentafel 1 h — Legitimation: Fußnote 1 Stundentafeln + § 3 VO) |
| **Einstieg** | mit Reifeprüfung, Berufsreifeprüfung oder Studienberechtigungsprüfung → Abschluss **Diplomprüfung** (Matura bereits vorhanden) |
| **Rechtsbasis** | BGBl. II Nr. 368/2022, Anlage 1.9 (6-sem Kolleg, Variante I.4); Referenz-Raster Anlage 1.10 (BGBl. II Nr. 262/2015 idF 383/2021) |
