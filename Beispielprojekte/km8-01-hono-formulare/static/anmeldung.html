Kursanmeldung

Zwei Formulare, zwei Methoden: Die Suche liest (GET), die Anmeldung verändert (POST). Öffne die DevTools (F12) → Netzwerk und beobachte, was beim Absenden passiert.

1 · GET — Suche (nichts wird verändert)

Der Begriff landet als ?q=… in der URL — deshalb ist das Ergebnis teilbar und wiederholbar.

2 · POST — Anmeldung (verändert etwas)

Jedes Feld mit name wird mitgeschickt — ein Feld ohne name kommt am Server nie an.
