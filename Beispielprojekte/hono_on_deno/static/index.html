Deno 2 + Hono 4 · Referenz-API

Mini-Hono-Referenz

Ein Rumpf aus statischer Auslieferung, JSON-API und Echtzeit-TypeScript-Transpilation. Die Shop-Seite konsumiert die API als Browser-TypeScript, das vom Server on demand gebuendelt wird.

Zum Musikgeschaeft

API-Endpunkte

  • GET /api/productsAlle Artikel (optional ?category=)
  • GET /api/products/:idEinzelner Artikel
  • POST /api/ordersBestellung anlegen (10 % ab 3 Artikeln)
  • GET /api/ordersVerkaufslog
  • DELETE /api/orders/:idBestellung stornieren
  • GET /api/statsKennzahlen
  • GET /client/shop.tsTranspiliertes Client-JavaScript

Auslieferung

Statische Assets kommen aus /static unter einem Origin; unbekannte Pfade fallen auf diese Seite zurueck (SPA-Fallback) – dasselbe Muster wie beim Deployment eines vite build.
